MioProxy is a Windows desktop client for managing a Mihomo-powered proxy runtime through a focused graphical interface.

- Subscription and profile management
- Proxy groups, node switching, and latency testing
- Windows System Proxy and TUN mode
- Rules, GeoSite, GeoIP, DNS, traffic, connections, and logs
- Windows Service integration and runtime recovery
- Signed application update flow
